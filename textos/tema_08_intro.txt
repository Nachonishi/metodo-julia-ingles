Los conditionals conectan una condición con un resultado. Zero Conditional se usa para hechos generales: If you heat ice, it melts. First Conditional para posibilidades reales futuras: If it rains, we will stay home. Second Conditional para situaciones imaginarias o poco probables: If I had wings, I would fly. En la parte con if del First Conditional usamos Present Simple, no will. Unless significa if not, salvo que o a menos que. No elijas por la palabra if solamente: preguntate qué tipo de situación expresa.
